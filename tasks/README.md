# Open Interview Tasks

This directory contains agent-facing task slices for Codex execution.

Rules:
- Product code must be authored by Codex CLI, not by agents directly.
- Tasks should be bounded, reviewable, and mapped back to canonical docs in `../docs/`.
- Each task file should define goal, scope, constraints, done-when, refs, and review checklist.
- Current execution slices live under `./slices/`.
