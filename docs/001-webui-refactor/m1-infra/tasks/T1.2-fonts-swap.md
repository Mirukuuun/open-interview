# T1.2 · 字体依赖切换（移除 IBM Plex / 新增 Inter）

## 目标

移除 `@fontsource/ibm-plex-sans` 和 `@fontsource/ibm-plex-mono` 依赖，新增 `@fontsource/inter`（400/500/600/700 四档 weight 或 variable 版本），保留 `@fontsource/jetbrains-mono`。在 `src/app/layout.tsx` 加 `html` 的 `font-sans` class 或等价处理，让 Inter 作为默认字体。

## 涉及文件

- **Modify**: `package.json`（依赖增减）
- **Modify（shared）**: `src/app/layout.tsx`（若需要显式挂 font class；注意与 T1.3 / T1.8 在同一文件上的修改协调）
- **Test**: `tests/fonts-swap.test.ts`（可选：解析 package.json 断言依赖清单）

## 验收条件

- [ ] `package.json` 中 `dependencies` 删除 `@fontsource/ibm-plex-sans` 和 `@fontsource/ibm-plex-mono` 两行
- [ ] `package.json` 中 `dependencies` 新增 `@fontsource/inter`（version 取 pnpm 最新稳定，建议 `^5.x`）
- [ ] `@fontsource/jetbrains-mono` 保留不动
- [ ] `corepack pnpm install` 成功，`pnpm-lock.yaml` 自动更新
- [ ] `src/app/layout.tsx` 中 `html` 或 `body` 元素带 `font-sans`（Tailwind 工具类，映射到 `var(--font-sans)`）
- [ ] `corepack pnpm build` 成功
- [ ] `corepack pnpm typecheck` 通过
- [ ] `grep -rn "ibm-plex" src/` 返回 0 行

## 依赖

- 前置：T1.1（globals.css 已更新字体栈变量为 Inter）
- 后置：T1.3（深色模式 ThemeProvider 挂在 layout.tsx）必须在本 task 完成后才开始，避免在 layout.tsx 上的并行写冲突

## Step 3 · 写最小实现

1. 修改 `package.json`：

```diff
 "dependencies": {
-    "@fontsource/ibm-plex-mono": "^5.2.7",
-    "@fontsource/ibm-plex-sans": "^5.2.8",
+    "@fontsource/inter": "^5.2.8",
     "@fontsource/jetbrains-mono": "^5.2.8",
```

2. 执行 `corepack pnpm install` 更新 lockfile。

3. 修改 `src/app/layout.tsx`：

```tsx
import type { Metadata } from "next";

import "./globals.css";

export const metadata: Metadata = {
  title: {
    default: "Open Interview",
    template: "%s | Open Interview",
  },
  description:
    "Open Interview is a local-first workbench for interview notes, question review, grounded QA, and resume deep dives.",
};

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html lang="en">
      <body className="font-sans antialiased">{children}</body>
    </html>
  );
}
```

> 注意：本 task 只动 `<body className="font-sans antialiased">` 这一处；T1.3 会在此基础上添加 ThemeProvider 和 suppressHydrationWarning，T1.8 会确认 root 结构最终形态。三者**串行**执行，不并行。
