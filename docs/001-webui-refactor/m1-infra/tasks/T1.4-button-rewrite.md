# T1.4 · Button 组件重写（5 variant × 4 size，全部 1px border 几何对齐）

## 目标

按 `design.md` §6 重写 `src/components/ui/button.tsx`：
- 5 variants：`primary / secondary / ghost / destructive / link`（link 无 border、无 min-height）
- 4 sizes：`sm 28px / md 34px / lg 40px / xl 46px`
- 所有 variant（除 link）带 1px border（透明或同色），几何严格对齐
- 保持现有 props 签名 `variant / href / children`；**新增 `size` prop 默认 `md`**，现有未传 `size` 的调用点行为上等价于"比旧 h-11 略矮"（旧 44px → 新默认 md 34px）——这**是有意的密度收敛**，不是兼容 break。
- 保留 `asChild` 或 `href` 作为 Link 切换的能力（保留现有 `LinkButtonProps` 判分派逻辑）
- Link variant 不带自动箭头
- Disabled 仅降 opacity 50%，不改 geometry
- `active:scale-[0.98]` 按压反馈、`focus-visible:ring` 用 brand 色

## 涉及文件

- **Modify**: `src/components/ui/button.tsx`
- **Test**: `tests/button.test.tsx`

## 验收条件

- [ ] `ButtonVariant` 类型为 `"primary" | "secondary" | "ghost" | "destructive" | "link"`
- [ ] `ButtonSize` 类型为 `"sm" | "md" | "lg" | "xl"`，`size` prop 可选，默认 `md`
- [ ] 每个 (variant × size) 组合有对应 Tailwind class（或 cva 定义）；几何：`h-7 / h-[34px] / h-10 / h-[46px]`；padding `px-2.5 / px-3.5 / px-4.5 / px-6.5`；font-size `text-xs / text-[13px] / text-sm / text-[15px]`
- [ ] 除 link 外所有 variant 带 `border`（class 明确 `border` 1px）；primary / destructive border 同背景色；secondary border `border-[color:var(--color-border)]`；ghost border `border-transparent`
- [ ] link variant 不带 border、min-height、padding（内联链接气质）；不自动加箭头
- [ ] `disabled:opacity-50 disabled:pointer-events-none disabled:cursor-not-allowed`
- [ ] `focus-visible:ring-2 focus-visible:ring-[color:var(--color-brand)] focus-visible:ring-offset-2 focus-visible:ring-offset-[color:var(--color-background)]`
- [ ] `active:scale-[0.98]`
- [ ] `transition-colors duration-150 ease-out`（或项目约定的 timing token）
- [ ] 保留 `isLinkButtonProps` 判分派逻辑，`href` → `<Link>`，无 `href` → `<button>`
- [ ] `corepack pnpm typecheck` 通过（下游 ~593 处用点不能 break，靠保留现有 `variant / href` 签名）
- [ ] `corepack pnpm lint` 通过
- [ ] Vitest 测试通过

## Step 3 · 写最小实现

重写 `src/components/ui/button.tsx`：

```tsx
import Link from "next/link";

import { cn } from "@/lib/utils";

export type ButtonVariant =
  | "primary"
  | "secondary"
  | "ghost"
  | "destructive"
  | "link";

export type ButtonSize = "sm" | "md" | "lg" | "xl";

const variantClasses: Record<ButtonVariant, string> = {
  primary:
    "border border-[color:var(--color-brand)] bg-[color:var(--color-brand)] text-white hover:bg-[color:var(--color-brand)]/90",
  secondary:
    "border border-[color:var(--color-border)] bg-[color:var(--color-surface)] text-[color:var(--color-foreground)] hover:bg-[color:var(--color-surface-subtle)]",
  ghost:
    "border border-transparent bg-transparent text-[color:var(--color-foreground)] hover:bg-[color:var(--color-surface-subtle)]",
  destructive:
    "border border-[color:var(--color-destructive)] bg-[color:var(--color-destructive)] text-white hover:bg-[color:var(--color-destructive)]/90",
  link:
    "text-[color:var(--color-brand)] underline-offset-4 hover:underline",
};

const sizeClasses: Record<Exclude<ButtonSize, never>, string> = {
  sm: "h-7 px-2.5 text-xs rounded-[var(--radius-md)]",
  md: "h-[34px] px-3.5 text-[13px] rounded-[var(--radius-md)]",
  lg: "h-10 px-4.5 text-sm rounded-[var(--radius-md)]",
  xl: "h-[46px] px-6.5 text-[15px] rounded-[var(--radius-md)]",
};

const linkSizeClasses: Record<ButtonSize, string> = {
  sm: "text-xs",
  md: "text-[13px]",
  lg: "text-sm",
  xl: "text-[15px]",
};

type SharedProps = {
  className?: string;
  variant?: ButtonVariant;
  size?: ButtonSize;
};

type ButtonProps = SharedProps &
  React.ButtonHTMLAttributes<HTMLButtonElement> & {
    href?: never;
  };

type LinkButtonProps = SharedProps &
  Omit<React.ComponentProps<typeof Link>, "className">;

function isLinkButtonProps(
  props: ButtonProps | LinkButtonProps,
): props is LinkButtonProps {
  return "href" in props && props.href !== undefined;
}

function buttonClasses(
  variant: ButtonVariant,
  size: ButtonSize,
  className?: string,
) {
  const isLink = variant === "link";
  const base =
    "inline-flex items-center justify-center font-medium transition-colors duration-150 ease-out active:scale-[0.98] focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[color:var(--color-brand)] focus-visible:ring-offset-2 focus-visible:ring-offset-[color:var(--color-background)] disabled:pointer-events-none disabled:cursor-not-allowed disabled:opacity-50";

  return cn(
    base,
    isLink ? linkSizeClasses[size] : sizeClasses[size],
    variantClasses[variant],
    className,
  );
}

export function Button(props: ButtonProps | LinkButtonProps) {
  if (isLinkButtonProps(props)) {
    const {
      children,
      className,
      href,
      variant = "secondary",
      size = "md",
      ...linkProps
    } = props;

    return (
      <Link className={buttonClasses(variant, size, className)} href={href} {...linkProps}>
        {children}
      </Link>
    );
  }

  const {
    className,
    type = "button",
    variant = "secondary",
    size = "md",
    ...buttonProps
  } = props;

  return (
    <button
      className={buttonClasses(variant, size, className)}
      type={type}
      {...buttonProps}
    />
  );
}
```

> **变更清单**（交付 T1.11 使用）：
> - `Variant` 从 3 → 5（新增 `destructive` / `link`）
> - 新增 `size` prop（默认 `md`，旧未传 size 等价于 `h-11` → 新默认 `h-[34px]`，这是 design.md §5.4 密度策略有意收敛）
> - 移除现有 `shadow-[0_1px_0_rgba(79,70,229,0.18)]`、`bg-accent` 类（换 token）
> - 旧 `rounded-[14px]` → 新 `rounded-[var(--radius-md)]`（6px）
