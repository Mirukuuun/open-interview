# T1.10 · Buffer（执行时 bug 修复记录 + 回归测试）

## 目标

**BUFFER**：为 T1.1 – T1.8 开发过程中或 T1.9 回归验证中发现的 bug / 视觉回归 / typecheck 红 / 不兼容 props 调用点爆破等问题提供修复槽位 + 配套回归测试的占位。

本 task 在 planning 阶段为占位；**执行阶段**由 executing-phase 根据 T1.9 report 填入实际内容：每个修复一个条目，包含复现步骤、根因、fix diff、回归测试文件、再跑一次完整 `db:init + typecheck + lint + build + test` 的通过记录。
