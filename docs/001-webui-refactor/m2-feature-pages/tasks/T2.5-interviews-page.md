# T2.5 · `/interviews` 页面重构（左右分栏来源列表 + 上下文）

## 目标

按 `design.md §9 P5` + `roadmap.md §5.2` 对 `/interviews` 进行布局重构：
1. 节奏切换为 **左侧来源列表 + 右侧上下文展示** 的分栏布局，与 P3/P4 的纯列表模式有明确差异化
2. 清理旧 token 类名 48 处 / 3 文件（见 §涉及文件）
3. 消费 M1 原子组件，杜绝 inline 样式 hack

## 轻量 Design Note（5 项最小覆盖）

> 本段即 `/interviews` 页面的轻量 design note。

### 1. 目标

让用户进入 `/interviews` 时感知"这是一个面经 / 考试记录浏览器"：左侧按来源（面经/模拟考试）分组的列表导航 + 右侧选中记录的详细内容和题目卡片。节奏为"主从分栏"——左侧导航定位，右侧展开详情，类似邮件客户端的双栏布局。

### 2. 布局骨架

```
+------------------------------------------------------------+
| PageHeader (紧凑): title="面经记录" + actions(筛选 Ghost)   |
+------------------------------------------------------------+
|                                                             |
| +------------------+ +----------------------------------+ |
| | 来源列表          | | 详情区                            | |
| | (280px flex-none) | | (flex-1 min-w-0)                 | |
| |                   | |                                  | |
| | SourceCard × N    | | interview-detail-workbench       | |
| | (按来源分组)      | |  · 基本信息 (DetailGrid)          | |
| |                   | |  · 题目卡片 (QuestionCard × N)   | |
| | EmptyList         | |  · EmptyList (无题目)            | |
| | (0 记录)          | |                                  | |
| +------------------+ +----------------------------------+ |
|                                                             |
+------------------------------------------------------------+
```

- **左侧来源列表**：`<aside className="w-70 flex-none border-r border-[color:var(--color-border)] overflow-y-auto">`；每个来源 Card 可点击选中，选中态 `bg-[color:var(--color-brand-soft)]`
- **右侧详情区**：`<main className="flex-1 min-w-0 overflow-y-auto">`；展示选中记录的 `DetailGrid`（meta 信息）+ `interview-question-card.tsx` 列表
- **响应式**：< 1024px 塌成单列（来源列表在上，详情在下）或 tab 切换

### 3. 按钮摆放

- **PageHeader 右上**：1 个 Ghost "筛选"（sm）；无 Primary（面经记录是只读浏览）
- **来源列表每项**：无按钮，整卡可点击；hover `hover:border-[color:var(--color-brand)]`
- **详情区 PageHeader**（内嵌）：可选 1 个 Secondary "导出"（sm）
- **空态（0 记录）**：`EmptyList` 标题"还没有面经记录" + Link "去做一套模拟"（跳转 `/practice`）

### 4. 空态

- **来源列表为空**：`EmptyList` 标题"还没有面经记录" + Link "去做一套模拟"
- **选中来源无题目**：详情区 `EmptyList` 标题"该记录暂无题目"
- **不引入插图**（延续全 phase 决策）

### 5. 明确不做

- **不动**：业务逻辑（面经记录的读取 / 分组逻辑 / server calls 不变）
- **不引入**：新装饰元素 / 新色阶 / 新圆角值
- **不引入**：面经记录编辑 / 删除等新功能
- **不引入**：虚拟滚动 / 分页（保留现有列表渲染方式）

## Step 3 · 写最小实现

按 §轻量 Design Note 重写 `src/features/interviews/*`：

1. **清旧 token 类名**（3 文件 48 处）：
   - `border-border-strong` / `border-border-muted` → `border-[color:var(--color-border)]`
   - `text-text-muted` → `text-[color:var(--color-muted-foreground)]`
   - `text-text-strong` → `text-[color:var(--color-foreground)]`
   - `bg-accent` → `bg-[color:var(--color-brand-soft)]`
   - `text-accent` → `text-[color:var(--color-brand)]`
2. **左右分栏布局**（`interview-list-workbench.tsx`）：
   - 外壳：`<div className="flex h-full">`
   - 左侧：`<aside className="w-70 flex-none border-r border-[color:var(--color-border)] overflow-y-auto">`
   - 右侧：`<main className="flex-1 min-w-0 overflow-y-auto">`
   - 来源卡片 hover `hover:border-[color:var(--color-brand)]` + 选中 `bg-[color:var(--color-brand-soft)]`
   - 空态消费 `EmptyList`
3. **详情密度重绘**（`interview-detail-workbench.tsx`）：
   - 消费 `DetailGrid` / `Card` / `Badge`
   - 紧凑 meta 区 + 平衡内容区
4. **题目卡片重绘**（`interview-question-card.tsx`）：
   - 消费 `Card` / `Badge`；hover `hover:border-[color:var(--color-brand)]`

实施时严格参考 `docs/reference/design-system.md §2 按钮摆放规则` + `§4 原子组件 API`。
