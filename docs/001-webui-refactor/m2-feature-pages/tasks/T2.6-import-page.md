# T2.6 · `/import` 页面重构（表单主导 + 分步感 + action panel 收敛）

## 目标

按 `design.md §9 P6` + `roadmap.md §5.2` 对 `/import` 进行布局重构：
1. 节奏切换为 **表单主导 + step 2 分步感** 的导入流程布局，将分散的多个 action panel 收敛到清晰的步骤结构中
2. 清理 M1 已知 cosmetic 退化：
   - `reveal-list` 1 处（`import-workbench.tsx:143`）
   - 旧 token 类名 32 处 / 3 文件（见 §涉及文件）
3. 消费 M1 原子组件（`Card` / `Button` / `Input` / `Select` / `Textarea` / `FormField` / `Badge` / `PageHeader`），杜绝 inline 样式 hack

## 轻量 Design Note（5 项最小覆盖）

> 本段即 `/import` 页面的轻量 design note。

### 1. 目标

让用户进入 `/import` 时感知"这是一个导入 / 上传工作流"：清晰的步骤引导（Step 1 选择来源 → Step 2 填写内容 → 提交），表单区域集中，action panel 收敛而非散落在不同卡片中。节奏为"表单引导流"——与列表页（P3/P4）和分栏页（P5）有明确差异化。

### 2. 布局骨架

```
+------------------------------------------------------------+
| PageHeader (紧凑): title="导入" + actions(无 Primary)       |
+------------------------------------------------------------+
| Step 指示器（轻量：Step 1 · 选择来源 → Step 2 · 填写内容）   |
+------------------------------------------------------------+
| 主表单区 (Card)                                             |
|  +------------------------------------------------------+  |
|  | Step 1: 来源选择                                       |  |
|  |  · 来源类型 Select                                     |  |
|  |  · 标签 CreatableMultiSelect                          |  |
|  +------------------------------------------------------+  |
|  | Step 2: 内容填写 (import-actions-panel.tsx 收敛)        |  |
|  |  · 各 action panel 内的表单字段                         |  |
|  |  · FormField × N (Input / Textarea / Select)           |  |
|  +------------------------------------------------------+  |
|  | 底部 action bar                                        |  |
|  |  · Primary "提交导入" (lg) + Secondary "取消"          |  |
|  +------------------------------------------------------+  |
+------------------------------------------------------------+
```

- **Step 指示器**：轻量文本指示（`text-[13px] text-[color:var(--color-muted-foreground)]`），不引入额外 stepper 组件
- **主表单区**：单个 `Card` 内嵌 2 个 step 区域，用 `SectionHeading` 分隔
- **action panel 收敛**：`import-actions-panel.tsx` 的多个分散 panel 收敛到 Step 2 的 Card 内部，用 `SectionHeading` 做视觉分隔
- **响应式**：< 768px 表单全宽，各字段堆叠单列

### 3. 按钮摆放

- **PageHeader 右上**：无 Primary（主 CTA 在底部 action bar，避免主视觉争夺）
- **底部 action bar**：1 个 Primary "提交导入"（lg）居右 + 1 个 Secondary "取消"居左；action bar 用 `sticky bottom-0` 或 Card footer
- **CreatableMultiSelect 标签**：内嵌 Ghost "添加"（sm），不独占主视觉
- **空态**：`EmptyList` 标题"还没有导入记录"（若导入页同时展示历史列表）；当前导入流为纯表单，无列表空态需求

### 4. 空态

- **导入页为表单主导**：无传统"列表为空"场景
- **表单验证错误态**：各 `FormField` 自带 error 展示（消费 M1 `FormField` 组件的 error prop）
- **不引入插图**（延续全 phase 决策）

### 5. 明确不做

- **不动**：业务逻辑（导入处理流程 / 文件上传 / server calls / `import-actions-panel.tsx` 内部业务逻辑不变）
- **不引入**：新装饰元素 / 新色阶 / 新圆角值
- **不引入**：拖拽上传 / 批量操作等新功能
- **不引入**：真正的 stepper 组件（用轻量文本指示替代）
