# T2.3 · `/questions` 页面重构（保留骨架 + 新密度重绘）

## 目标

按 `design.md §9 P3` + `roadmap.md §5.2` 对 `/questions` 进行布局重构：
1. 保留 Header + filter + list 骨架，按 M1 新密度策略（Header 紧凑 / Body 平衡）和新组件重绘
2. 清理旧 token 类名 42 处 / 2 文件

## 轻量 Design Note（5 项最小覆盖）

> 本段即 `/questions` 页面的轻量 design note。

### 1. 目标

让用户进入 `/questions` 时感知"这是一个题库浏览 / 筛选页面"：顶部紧凑 Header + 筛选区 + 下方题目列表卡片流。节奏偏"中性列表"——不需要 `/practice` 那样的三段分区，也不需要 `/qa` 的对话感，保持"搜索 → 浏览 → 点击进入详情"的标准 CRUD 列表体验。

### 2. 布局骨架

```
+------------------------------------------------------------+
| PageHeader (紧凑): title="题库" + actions(搜索/筛选 toggle) |
+------------------------------------------------------------+
| 筛选区 (可折叠)                                             |
|  · 分类 Select + 难度 Select + 关键词 Input                 |
|  · 紧凑行高，gap-3                                          |
+------------------------------------------------------------+
| 题目列表                                                    |
|  +------------------------------------------------------+  |
|  | QuestionCard (Card)                                    |  |
|  |  · 标题 + Badge(难度/分类) + meta(来源/更新时间)        |  |
|  |  · 点击进入 question-detail                            |  |
|  +------------------------------------------------------+  |
|  | QuestionCard × N                                       |  |
|  +------------------------------------------------------+  |
|  | EmptyList (筛选无结果 / 题库为空)                       |  |
|  +------------------------------------------------------+  |
+------------------------------------------------------------+
```

- **顶部**：`PageHeader` 紧凑档，actions 区域放筛选 toggle（`<Button variant="ghost" size="sm">`）
- **筛选区**：紧凑行高，消费 M1 `Input` / `Select` 组件；可折叠（默认展开）
- **题目列表**：单列卡片流，每张 `Card` 内含标题 + `Badge` 标签 + meta 信息；点击整卡进入详情
- **响应式**：< 768px 筛选区堆叠为单列

### 3. 按钮摆放

- **PageHeader 右上**：无 Primary（题库是只读浏览，无主 CTA）；1 个 Ghost "筛选"（sm，toggle 筛选区可见性）
- **每张题目卡片**：无按钮，整卡可点击（`hover:border-[color:var(--color-brand)]` 替代旧样式）
- **题目详情页（question-detail-workbench.tsx）**：PageHeader 右上 1 个 Primary "开始练习"（lg），跳转 `/practice/drill?questionId=...`
- **空态**：`EmptyList` 标题"还没有题目" + `xl` Primary "导入题目"（跳转 `/import`）

### 4. 空态

- **题库为空**：`EmptyList` 标题"还没有题目" + `xl` Primary "导入题目" + Link "了解导入流程"
- **筛选无结果**：`EmptyList` 标题"没有匹配的题目" + Secondary "清除筛选条件"
- **不引入插图**（延续全 phase 决策）

### 5. 明确不做

- **不动**：业务逻辑（题目 CRUD / 筛选逻辑 / `question-query-state.ts` 状态管理不变）
- **不引入**：新装饰元素 / 新色阶 / 新圆角值
- **不引入**：分页 / 无限滚动等新功能（保留现有列表渲染方式）

## Step 3 · 写最小实现

按 §轻量 Design Note 重写 `src/features/questions/*`：

1. **清旧 token 类名**（2 文件 42 处）：
   - `border-border-strong` / `border-border-muted` → `border-[color:var(--color-border)]`
   - `text-text-muted` → `text-[color:var(--color-muted-foreground)]`
   - `text-text-strong` → `text-[color:var(--color-foreground)]`
   - `bg-accent` → `bg-[color:var(--color-brand-soft)]`
   - `text-accent` → `text-[color:var(--color-brand)]`
2. **密度重绘**（`question-bank-workbench.tsx`）：
   - `PageHeader` 紧凑档：仅 `title="题库"` + actions（Ghost "筛选"）
   - 筛选区消费 M1 `Input` / `Select`；紧凑行高 `gap-3`
   - 题目列表消费 `Card` / `Badge`；hover 用 `hover:border-[color:var(--color-brand)]`
   - 空态消费 `EmptyList`
3. **密度重绘**（`question-detail-workbench.tsx`）：
   - `PageHeader` 紧凑档：`title={题目标题}` + actions（Primary "开始练习" lg）
   - 内容区消费 `Card` / `DetailGrid` / `Badge`
   - 所有 `SurfaceCard` 消费方式保持兼容

实施时严格参考 `docs/reference/design-system.md §2 按钮摆放规则` + `§4 原子组件 API`；不引入新 variant / 新 size / 新 token。
