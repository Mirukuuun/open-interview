# T2.1 · `/practice` 页面重构（灯塔页）

## 目标

按 `design.md §9 P1` + `roadmap.md §5.2` 对 `/practice` 进行布局重构：
1. 节奏切换为 **顶部总览主卡 + 主舞台 + 右侧最近考试** 的三段布局（摆脱现有"左侧长栏 + 杂乱卡片"）
2. 雷达图装饰动画决策闭环（对应 `design.md §12` 未决事项 1：保留静态雷达 vs 换能力画像）
3. 清理 M1 已知 cosmetic 退化：
   - `radar-draw` 1 处（`practice-radar-chart.tsx:156`）
   - `reveal-list` 1 处（`practice-recent-exams-panel.tsx:31`）
   - 旧 token 类名 63 处 / 8 文件（见 §涉及文件）
4. 作为"灯塔页"优先验证 M1 原子组件 / workbench 组件 / tokens 在真实页面消费时的完整性；若发现缺口，走 T2.10 buffer + 独立 m1-infra patch PR（不扩大 M2 范围）

## 轻量 Design Note（5 项最小覆盖）

> 对齐 `roadmap.md §5.2`"每页启动时产物：一份轻量 design note（一页 markdown）"；本段即该页的 design note，不另开文件。

### 1. 目标

让用户进入 `/practice` 时立即感知"这是一个训练 / 考试工作台"：顶部一屏内呈现训练进度 + 今日推荐 + 快速入口；主舞台承载主要动作（开始训练 / 查看画像）；右侧边栏呈现最近考试记录，提供"继续刷"的 affordance。

### 2. 布局骨架

```
+------------------------------------------------------------+
| PageHeader (紧凑): title="训练" + actions(开始训练 lg)      |
+------------------------------------------------------------+
| OverviewCard (3 列 KV row, 基于 DetailGrid)                |
|  · 累计训练 · 本周训练 · 待复习                             |
+------------------------------------------------------------+
|                                                             |
|  +-------------------------+  +--------------------------+ |
|  | 主舞台 (Card)           |  | 最近考试 (Card)          | |
|  |  · 今日训练推荐          |  |  · RecentExamCard × N   | |
|  |  · 能力画像摘要          |  |  · EmptyList (xl CTA)   | |
|  |  · ProfileGrid / 雷达    |  |                          | |
|  +-------------------------+  +--------------------------+ |
|   (flex-[3])                   (flex-[2], min-w 320px)     |
|                                                             |
+------------------------------------------------------------+
```

- **顶部总览**：`PageHeader` 紧凑档 + 独立 `OverviewCard`（单行 3 KV），不再用旧 highlights grid
- **主舞台**：`Card` + `CardHeader`（title + 次级 action）+ `CardBody`（能力画像 / drill 推荐）
- **右侧最近考试**：`Card` + `CardBody` 内 `RecentExamCard` 列表（去 `.reveal-list`，静态直出）
- **响应式**：< 1024px 塌成单列（主舞台在上，最近考试在下）

### 3. 按钮摆放

- **PageHeader 右上**：1 个 Primary（`<Button size="lg" variant="primary">开始训练</Button>`），链到 `/practice/drill`
- **主舞台 CardHeader 右**：1 个 Secondary（`<Button size="sm" variant="secondary">查看画像</Button>`），可选；不与 PageHeader Primary 抢主视觉
- **最近考试 CardHeader 右**：1 个 Link（`<Button variant="link">查看全部</Button>`），链到 `/interviews`
- **empty state**（最近考试 0 条）：`EmptyList` 内 1 个 `xl` Primary 独占一行（"做第一套模拟"）+ 下方 Link 说明
- 一个语境最多 1 个 Primary；整页 Primary 数量 ≤ 1（PageHeader 右上）

### 4. 空态

- **最近考试列表为空**：`EmptyList` 标题"还没有考试记录" + `xl` Primary"做第一套模拟" + Link"了解训练流程"
- **能力画像为空**（首次进入无数据）：主舞台内展示引导卡 + `xl` Primary"初始化画像"
- 不引入插图（对应 `design.md §12` 未决事项 3："当前无插图，Phase 2 是否引入" → 本页决策：**不引入**，保持克制）

### 5. 明确不做

- **不动**：业务逻辑（`practice-view-model.ts` / `practice-workbench-state.ts` 的数据契约、route props、server calls 不变）
- **不动**：`/practice/drill` / `/practice/exam` 子路由（本 task 只动 `/practice` 落地页和子组件；子路由若独立页面另议）
- **雷达图决策**：如果保留 → 去 `radar-draw` animation style，改静态直出（SVG / canvas 不动）；如果替换 → 用 `practice-profile-grid` 的 KV 形式呈现，删除 `practice-radar-chart.tsx`；**默认选保留静态**（实施时执行人确认；本 design note 不强制 A/B）
- **不引入**：新装饰元素 / 新色阶 / 新圆角值（完全消费 M1 tokens）
