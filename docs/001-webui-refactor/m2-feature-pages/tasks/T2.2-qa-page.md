# T2.2 · `/qa` 页面重构（聊天气泡 + 会话抽屉）

## 目标

按 `design.md §9 P2` + `roadmap.md §5.2` 对 `/qa` 进行布局重构：
1. 节奏切换为 **左侧会话抽屉 + 右侧聊天主区（单列气泡）** 的对话界面风格，摆脱当前"会话列表 + ask 表单平铺"的雷同节奏
2. 闭环 `design.md §12` 未决事项 2：气泡形态决策（见 §轻量 Design Note §2）
3. 清理 M1 已知 cosmetic 退化：
   - `interactive-card` 5 处（`qa-session-workbench.tsx:214` / `qa-workbench.tsx:108` / `qa-ask-form.tsx:197` / `qa-workbench-shell.tsx:119,324`）

   - `eyebrow=` 1 处（`qa-workbench.tsx:57` — `eyebrow="Grounded QA"`，已被 PageHeader 静默忽略）
   - 内联 `radial-gradient` 1 处（`qa-workbench-shell.tsx:397`）
   - 旧 token 类名 92 处 / 5 文件（见 §涉及文件）

## 轻量 Design Note（5 项最小覆盖）

> 对齐 `roadmap.md §5.2`"每页启动时产物：一份轻量 design note"；本段即该页的 design note。

### 1. 目标

让用户进入 `/qa` 时立即感知"这是一个对话界面"：左侧抽屉呈现历史会话列表（可搜索 / 新建）；右侧主区单列气泡流 + 底部输入区；整体节奏接近"聊天应用"而非"dashboard 卡片列表"。

### 2. 布局骨架

```
+----------------------------------------------+
| PageHeader (紧凑): title="QA" + actions(新建) |
+----------------------------------------------+
|                                                |
| +----------+ +------------------------------+ |
| | 会话抽屉  | | 聊天主区                      | |
| | (240px    | |                              | |
| |  min-w)   | |  [气泡流 — 单列上下排列]      | |
| |           | |  AI 回复左对齐               | |
| | 会话卡片   | |  用户提问右对齐               | |
| | × N      | |  引用 snippet inline 折叠     | |
| |           | |                              | |
| | EmptyList | |  +------------------------+  | |
| | (0 会话)  | |  | 输入区 (AskForm)       |  | |
| |           | |  +------------------------+  | |
| +----------+ +------------------------------+ |
|  (flex-none)  (flex-1, min-w-0)               |
+----------------------------------------------+
```

**`design.md §12` 未决闭环 — 气泡形态决策**：
- **单列 vs 左右分列**：采用**单列**。理由：QA 场景为用户提问 → AI 回答的 1:1 对话，无多人参与，左右分列浪费水平空间且增加视觉跳跃；单列上下排列更符合"对话流"的阅读节奏，用户提问右对齐 + AI 回复左对齐的方式提供足够的角色区分。
- **引用 snippet 是否 inline**：采用**inline 折叠**。理由：AI 回复中的引用 snippet 作为回复正文的一部分 inline 展示，默认折叠（`<details>`）显示来源摘要标题，点击展开查看完整引用内容；这样保持对话流的紧凑性，同时保留用户追溯引用来源的能力。

**响应式**：< 768px 左侧会话抽屉收起为 overlay（类似 sidebar 的移动端策略），聊天主区占满宽度。

### 3. 按钮摆放

- **PageHeader 右上**：1 个 Primary（`<Button size="lg" variant="primary">新建会话</Button>`），创建新 QA 会话
- **会话抽屉每个会话卡片**：无按钮，整个卡片可点击（用 `hover:border-[color:var(--color-brand)]` 替代旧 `.interactive-card`）；选中态用 `bg-[color:var(--color-brand-soft)]`
- **输入区**：1 个 Primary（`<Button size="md" variant="primary">发送</Button>`），位于输入区右下角；一个语境最多 1 个 Primary，输入区是独立语境
- **空态（0 条会话）**：`EmptyList` 标题"还没有 QA 会话" + `xl` Primary"开始第一次提问"
- 删除会话：`qa-session-delete-button.tsx` 用 `<Button variant="destructive" size="sm">`，不与 Primary 并排

### 4. 空态

- **会话列表为空（左侧抽屉）**：`EmptyList` 标题"还没有 QA 会话" + `xl` Primary"开始第一次提问" + Link"了解 QA 功能"
- **选中会话无消息（右侧主区）**：引导文案"输入你的问题开始对话" + 输入区聚焦
- **空态不引入插图**（延续 T2.1 决策：不引入，保持克制）

### 5. 明确不做

- **不动**：业务逻辑（QA session 的 CRUD / AI 调用 / streaming / server calls 不变）
- **不动**：`qa-session-delete-button.tsx` 的交互逻辑（只做旧 token 类名替换）
- **不引入**：新装饰元素 / 新色阶 / 新圆角值（完全消费 M1 tokens）
- **不引入**：消息编辑 / 消息删除 / 表情反应等新功能
- **去除**：`qa-workbench-shell.tsx:397` 内联 `radial-gradient` 背景（克制优先，改为 `bg-[color:var(--color-surface)]` 或 `bg-[color:var(--color-surface-muted)]`）
- **去除**：`eyebrow="Grounded QA"` 参数传递（PageHeader 已无 eyebrow 渲染）
